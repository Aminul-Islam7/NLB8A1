# TypeScript & OOP: Problem Solving & Blog Writing

Programming Hero Next Level (Level 2), Batch 8, Assignment 1. This repository contains my solutions to 8 TypeScript problems and two blog posts on core TypeScript concepts.

## Solutions

All solutions are in [`solutions.ts`](./solutions.ts). They cover:

| Problem | Function / Class | Concept |
| --- | --- | --- |
| 1 | `multiplyValue` | Default parameters |
| 2 | `processInput` | Union types, type narrowing |
| 3 | `formatCoordinate` | Readonly tuples |
| 4 | `concatenateArrays` | Generics, rest parameters |
| 5 | `Course`, `getPopularCourses` | Interfaces, array filtering |
| 6 | `pluckValues` | Generics with `keyof` |
| 7 | `Employee`, `Manager` | Classes, inheritance, access modifiers |
| 8 | `validateAgeAsync` | Promises, `setTimeout` |
